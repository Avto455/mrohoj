# Задача: переделать систему хирургического рисования на UILineRenderer

В Unity-проекте уже существует UI-интерфейс хирургии. Текущая реализация рисования мышью работает нестабильно.

Нужно заменить самописную отрисовку линий на компонент UILineRenderer из Unity UI Extensions.

Документация:
https://unity-ui-extensions.github.io/ugui/controls/ui-line-renderer/

GitHub:
https://github.com/Unity-UI-Extensions/com.unity.uiextensions

## 1. Сначала изучи проект

Перед изменениями:

- Найди существующие скрипты хирургического рисования.
- Найди Canvas и изображение пациента.
- Определи Render Mode Canvas.
- Проверь используемую систему ввода: старый Input Manager или New Input System.
- Найди существующую логику проверки паразитов.

Не удаляй рабочую логику проверки хирургии. Меняется только способ получения координат и отображения линий.

## 2. Архитектура

Раздели систему на следующие обязанности:

SurgeryInput:
- Получает события мыши через IPointerDownHandler, IDragHandler, IPointerUpHandler.
- Проверяет, что активен режим Surgery.
- Проверяет, что курсор находится внутри области пациента.
- Преобразует координаты мыши в локальные координаты drawingArea.
- Хранит точки текущего штриха.

SurgeryStrokeRenderer:
- Использует UILineRenderer.
- Отображает точки текущего штриха.
- Позволяет очищать линию.
- Позволяет завершить и сохранить контур.
- Поддерживает несколько отдельных контуров.

SurgeryEvaluator:
- Получает сохранённые контуры.
- Проверяет попадание паразитов внутрь контуров.
- Не занимается обработкой мыши и отрисовкой.

## 3. Получение координат

Используй:

RectTransformUtility.ScreenPointToLocalPointInRectangle()

Не вычисляй координаты Canvas вручную.

Учитывай Canvas Render Mode:
- Screen Space Overlay: eventCamera = null.
- Screen Space Camera: использовать worldCamera Canvas.
- World Space: использовать камеру Canvas.

Все точки должны быть выражены в локальных координатах RectTransform, к которому привязан UILineRenderer.

## 4. Правила рисования

- ЛКМ внутри drawingArea начинает новый штрих.
- Движение мыши добавляет точки.
- Не добавлять новую точку, если расстояние от предыдущей меньше минимального порога.
- При отпускании ЛКМ завершить штрих.
- Штрих считается контуром только если его конец достаточно близок к началу.
- При завершении автоматически соединить последний пункт с первым.
- Незамкнутый штрих не передавать в SurgeryEvaluator.
- Не объединять разные штрихи в один контур.
- Добавить возможность очистить последний штрих или все штрихи.

## 5. Настройки отображения

Настраиваемые поля:
- lineColor;
- lineThickness;
- minimumPointDistance;
- closureDistance;
- smoothing / resolution.

Линия должна быть видна поверх изображения пациента.

Не использовать LineRenderer из 3D-системы Unity.

Учитывать особенности UILineRenderer: собственный дочерний RectTransform, нулевой локальный offset и pivot (0, 0), согласно документации.

## 6. Проверка

Сначала создай тестовую сцену или тестовый режим с одним изображением пациента.

Проверить:
1. Рисование по диагонали.
2. Рисование круга.
3. Рисование небольшого контура.
4. Быстрое движение мыши.
5. Медленное движение мыши.
6. Выход курсора за границу drawingArea.
7. Отпускание мыши за пределами области.
8. Несколько отдельных контуров.
9. Переключение XRay / Surgery во время работы.
10. Отключение рисования при выходе из Surgery.

Не приступать к изменению алгоритма проверки паразитов, пока рисование не работает стабильно.

## 7. Ограничения

- Не переписывать весь GameFlowController.
- Не менять существующий дизайн UI.
- Не менять структуру данных пациентов без необходимости.
- Не добавлять сторонние плагины кроме UILineRenderer.
- Не создавать новую систему хирургии с нуля, если можно адаптировать существующую.

После реализации сообщить, какие файлы изменены, какие компоненты добавлены в Inspector и какие тесты выполнены.
